Виджеты это панели, из которых состоит [макет](/ru/layouts). Откройте панель **Добавить виджет**, найдите нужный поиском или по категориям и перетащите его на сетку.

## Графики

| Виджет | Описание |
| --- | --- |
| График цены | Полноценный торговый график рынка с инструментами рисования и индикаторами. |
| График ликвидаций | Тепловая карта ликвидаций, показывающая, где принудительно закрываются позиции с плечом. Смотрите [Торговые индикаторы](/ru/trading-indicators). |
| График стопов | Тепловая карта стоп-лоссов, показывающая скопления стопов. |
| Историческая ставка фандинга | Ставка финансирования во времени на рынке бессрочных контрактов, чтобы замечать устойчивое давление лонгов или шортов. |
| Тепловая карта когорт | Позиционирование когорт по разным рынкам в одной сетке, чтобы сразу видеть, какие группы где в лонге или шорте. |
| Price heatmap | Динамика цен по набору активов, размер и цвет зависят от величины движения. |

## Лента

| Виджет | Описание |
| --- | --- |
| Стакан | Актуальные заявки на покупку и продажу по связанному рынку, с глубиной. |
| Стакан (Node) | Стакан, получаемый напрямую с ноды Hyperliquid. |
| Сделки | Лента сделок по связанному рынку в реальном времени. |
| Новости | Заголовки в реальном времени. Нажмите на тикер в заголовке, чтобы сразу торговать им через [Быструю торговлю](/ru/quicktrade). |

## Портфель

| Виджет | Описание |
| --- | --- |
| Позиции | Ваши открытые позиции: вход, цена ликвидации, размер и нереализованный PnL. |
| Балансы | Ваши балансы на бессрочных контрактах и споте. |
| Открытые ордера | Ваши отложенные ордера, отменяются прямо из таблицы. |
| TWAP | Ваши собственные исполняющиеся TWAP-ордера и их прогресс. |
| Текущие TWAP | Активные TWAP других трейдеров на рынке, который вы смотрите. |
| Исполнения | Ваши отдельные исполнения. |
| История | История ваших завершённых сделок. |
| Переводы | Пополнения, выводы и переводы по вашему аккаунту. |
| Копитрейд | Ваши активные копитрейдинговые связи и их результаты. Смотрите [Копитрейдинг](/ru/copy-trade). |
| Список отслеживания | Активы, отмеченные звёздочкой. Одновременно служит источником, за которым могут следовать другие виджеты, об этом ниже. |

## Связывание виджетов

По умолчанию каждый виджет показывает тот актив, на который его направили. Связывание соединяет виджеты так, что смена актива в одном меняет его во всех, и именно это превращает набор виджетов в рабочий терминал.

### Группы связи

Групп связи шесть, у каждой свой цвет. Откройте меню связи в заголовке виджета и выберите цвет, чтобы добавить виджет в группу.

| Группа | Цвет |
| --- | --- |
| 1 | Синий |
| 2 | Жёлтый |
| 3 | Фиолетовый |
| 4 | Красный |
| 5 | Оранжевый |
| 6 | Бирюзовый |

Все виджеты одной группы следуют за одним активом. Поместите график цены, стакан и ленту сделок в синюю группу, и они будут переключаться вместе. Поместите второй набор в жёлтую, и вы сможете держать рядом два рынка, не мешая один другому.

Виджеты, не связанные ни с чем, можно перевести в режим **Нет**: они останутся на том активе, который вы задали, что бы ни делала остальная часть макета.

### Цель

**Цель** это отдельная роль без номера. Виджет в режиме Цели следует за активом, которым вы торгуете, а не за цветовой группой. Роль Цели могут занимать только График цены и Быстрая торговля.

### Следование за списком наблюдения

Связывание не ограничено одним активом. Виджеты **Список наблюдения** и **Price heatmap** могут выступать источником для группы, и тогда они передают следующим за ними виджетам целый список активов, а не один тикер.

Так макет управляется списком: отметьте звёздочкой интересующие активы, направьте остальную часть макета на Список наблюдения, и виджеты, умеющие принимать список, будут работать со всем вашим списком, а не с одним рынком.

<Note>
  Связать можно не каждый виджет. Виджеты с данными вашего собственного аккаунта, такие как Позиции, Балансы и Исполнения, относятся к вам, а не к рынку, поэтому следовать им не за чем.
</Note>
