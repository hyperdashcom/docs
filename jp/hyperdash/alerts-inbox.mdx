---
title: "アラートと受信ボックス"
description: "アナウンス、システムアラート、リワード、ダイレクトメッセージ、追跡ウォレットのアクティビティを1か所で。"
---

受信ボックスはHyperdashの通知センターです。プラットフォームのアナウンス、システム通知、アラート、リワードやマイルストーンの更新、ダイレクトメッセージを1つのパネルに集約し、取引中もリアルタイムで更新されます。

## 受信ボックスの場所

ヘッダー右上のベルアイコンをクリックすると受信ボックスが開きます。未読アイテムがあるとベルにオレンジのドットが付き、パネル内に未読数が表示されます。ビューは3つのタブで絞り込めます。**すべて**、**メッセージ**、**アラート**です。

## 受信ボックスに届くもの

| 種類 | 内容 |
| --- | --- |
| アナウンス | 全ユーザーに配信されるプロダクトとプラットフォームのニュース |
| システム通知 | 自分宛てに直接送られるアカウントレベルの通知 |
| アラート | 注意が必要な可能性のある警告 |
| マイルストーン | 達成の通知 |
| リワード付与 | リワードがアカウントに入金されたときの確認 |
| VIP招待 | VIPプログラムへの招待 |
| ダイレクトメッセージ | 他のHyperdashユーザーとの1対1の会話 |

通知には、関連ページに直接ジャンプするボタンが含まれることがあります。

## 仕組み

- 受信ボックスはリアルタイム接続で常時ライブなので、パネルを閉じている間も未読バッジが更新されます。
- 受信ボックスを開くと、アナウンスとシステム通知は既読になります。ダイレクトメッセージは、そのスレッドを開いたときに既読になります。
- ダイレクトメッセージはスレッドビューから返信できます。アナウンスとシステムのチャンネルは読み取り専用です。
- 受信ボックス下部の**お問い合わせ**ボタンからフィードバックフォームを開けます。

## 追跡ウォレットのアラート

フォローしているウォレットのアクティビティは受信ボックスには届きません。トレーディングターミナルのライブの**追跡中**フィードに流れます。方向、サイズ、価格付きの取引に加えて、入出金などのアカウントイベントも表示されます。フィードはリスト、方向、オープンかクローズか、想定元本サイズで絞り込めます。ウォレットのフォローを始めるには[トレーダー探索](/jp/hyperdash/wallet-explore)を参照してください。

<Note>
  受信ボックスはHyperdashにサインインしている場合にのみ利用できます。
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="アプリの外でも通知を受け取れますか？">
    受信ボックスが主要チャンネルです。Hyperdashのアナウンスはメールでも届くことがあり、いつでも配信解除できます。さらにHyperdashは、アプリのヘッダーからリンクされたTelegramの公開クジラアラートチャンネルを運営しています。
  </Accordion>

  <Accordion title="フォローしているトレーダーが動いたときにアラートを受け取るには？">
    [トレーダー探索](/jp/hyperdash/wallet-explore)からウォレットを追跡してください。そのトレーダーの約定とアカウントイベントが、追跡中フィードにリアルタイムで表示されます。
  </Accordion>

  <Accordion title="未読バッジが消えたのはなぜですか？">
    アナウンスとシステム通知は全文がリストに表示されるため、受信ボックスを開くと既読としてカウントされます。ダイレクトメッセージは、スレッドを開くまで未読数が保持されます。
  </Accordion>

  <Accordion title="通知に返信できますか？">
    アナウンスとシステム通知は読み取り専用です。他のHyperdashユーザーからのダイレクトメッセージには、スレッドビューから直接返信できます。
  </Accordion>
</AccordionGroup>
