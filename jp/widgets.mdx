ウィジェットは[レイアウト](/jp/layouts)を構成するパネルです。**ウィジェットを追加**ドロワーを開き、検索またはカテゴリから探して、グリッドにドラッグします。

## チャート

| ウィジェット | 説明 |
| --- | --- |
| 価格チャート | マーケットの完全な取引チャート。描画ツールとインジケーターを備えています。 |
| 清算チャート | レバレッジポジションが強制決済される水準を示す清算ヒートマップ。[取引インジケーター](/jp/trading-indicators)をご覧ください。 |
| ストップチャート | ストップロスが集中している水準を示すストップヒートマップ。 |
| 過去の資金調達率 | 無期限先物マーケットの資金調達率の推移。継続的な買い圧力または売り圧力の把握に使えます。 |
| コホートヒートマップ | 複数マーケットにわたるコホートのポジションを1つのグリッドで表示し、どの層がどこで買い越しか売り越しかを一目で把握できます。 |
| Price heatmap | 複数銘柄の価格パフォーマンスを、変動幅に応じた大きさと色で表示します。 |

## フィード

| ウィジェット | 説明 |
| --- | --- |
| オーダーブック | リンクしたマーケットのリアルタイムの買い気配と売り気配、および板の厚み。 |
| オーダーブック (Node) | Hyperliquidのノードから直接取得した板情報。 |
| 取引 | リンクしたマーケットのリアルタイムの約定履歴。 |
| ニュース | リアルタイムのヘッドライン。ヘッドライン上のティッカーをクリックすると、[クイックトレード](/jp/quicktrade)でその場から取引できます。 |

## ポートフォリオ

| ウィジェット | 説明 |
| --- | --- |
| ポジション | 保有中のポジション。建値、清算価格、数量、未実現損益を表示します。 |
| 残高 | 無期限先物とスポットの残高。 |
| 未約定注文 | 板に出ている自分の注文。テーブルから取り消せます。 |
| TWAP | 自分が実行中のTWAP注文と進捗。 |
| 現在のTWAP | 表示中のマーケットで他のトレーダーが実行中のTWAP。 |
| 約定 | 個別の約定履歴。 |
| 履歴 | 完了した取引履歴。 |
| 送金 | アカウントへの入金、出金、送受金。 |
| コピートレード | 進行中のコピートレードの関係とその成績。[コピートレーディング](/jp/copy-trade)をご覧ください。 |
| ウォッチリスト | スターを付けた銘柄。下記のとおり、他のウィジェットが追随する供給元にもなります。 |

## アルファ

| ウィジェット | 説明 |
| --- | --- |
| トップトレーダー | そのマーケットで最大のポジション。建値、清算価格、損益、コピースコアを表示します。 |
| コホート | 損益層とウォレット規模ごとに、各トレーダーコホートがそのマーケットでどのようなポジションを取っているかを表示します。 |
| ポジション変更 | 15分から7日までの期間で、トレーダーのポジションがどう変化したかを表示します。 |
| トラッキング | 追跡中のウォレットのリアルタイムの動き。[ウォレット追跡](/jp/wallet-explore)をご覧ください。 |

アルファ系ウィジェットの詳しい内容は、[コホート、トップトレーダー、ポジション変化](/jp/cohorts-top-traders-position-changes)をご覧ください。

## ツール

| ウィジェット | 説明 |
| --- | --- |
| クイックトレード | あらかじめ設定したサイズでワンクリック発注するボタン。[クイックトレード](/jp/quicktrade)をご覧ください。 |

## ウィジェットリンク

既定では、各ウィジェットは指定された銘柄を表示します。リンクはウィジェット同士を結び付け、1つで銘柄を変えるとすべてが一緒に切り替わるようにします。ばらばらのウィジェットの集まりを、実用的なターミナルに変えるのがこの機能です。

### リンクグループ

リンクグループは色ごとに6つあります。ウィジェットのヘッダーでリンクメニューを開き、色を選ぶとそのグループに追加されます。

| グループ | 色 |
| --- | --- |
| 1 | ブルー |
| 2 | イエロー |
| 3 | パープル |
| 4 | レッド |
| 5 | オレンジ |
| 6 | ティール |

同じグループのウィジェットはすべて同じ銘柄に追随します。価格チャート、板、約定フィードをブルーに入れれば一緒に動きます。2組目をイエローに入れれば、互いに干渉することなく2つのマーケットを並べて見られます。

どこにもリンクしないウィジェットは**なし**に設定できます。レイアウトの他の部分が何をしていても、指定した銘柄のまま留まります。

### ターゲット

**ターゲット**は番号のない独立した役割です。ターゲットに設定したウィジェットは、色グループではなく現在取引している銘柄に追随します。ターゲットの役割を担えるのは価格チャートとクイックトレードだけです。

### ウォッチリストに追随させる

リンクは単一銘柄に限りません。**ウォッチリスト**と **Price heatmap** のウィジェットはグループの供給元になれます。その場合、1つのティッカーではなく銘柄のリスト全体を、追随するウィジェットへ渡します。

リストでレイアウトを動かす方法です。気になる銘柄にスターを付け、レイアウトの残りをウォッチリストに向ければ、リストを受け取れるウィジェットは単一のマーケットではなくウォッチリスト全体を扱います。

<Note>
  すべてのウィジェットがリンクできるわけではありません。ポジション、残高、約定のように自分のアカウント情報を表示するウィジェットは、マーケットではなく利用者自身に関するものなので、追随する対象がありません。
</Note>
