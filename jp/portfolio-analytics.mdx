プロフィールは自分のアカウントに関するすべての拠点です。合計エクイティ、オープンポジション、有効な注文、完全な取引履歴、そして取引から算出されるパフォーマンス分析が集まります。Hyperdashのすべてのトレーダープロフィールが同じレイアウトで動いているため、他人を分析するときに見る統計と、自分に表示される統計は同じものです。

## アカウント概要

| セクション | 表示内容 |
| --- | --- |
| 口座価値 | パーペチュアル、スポット、ステーキング、コピートレードの各残高に分解された合計エクイティ |
| 概要 | 未実現PNL、アカウントレバレッジ、証拠金使用率、累計PNL、出来高 |
| パフォーマンス | ドローダウン、勝率、シャープレシオ。7日、30日、累計を切り替えできます |
| 分析 | 最長連勝、トレーディングスタイル、平均・中央値の取引期間、PNLコホートとサイズコホート |

トレーディングスタイルは平均取引期間で分類されます。スキャルプ（15分未満）、イントラデイ（15分から6時間）、スイング（6時間から2週間）、ポジション（2週間超）、アルゴリズムです。並んで表示されるウィジェットで、ロング/ショートの方向バイアス、レバレッジ、証拠金使用率をひと目で確認できます。

## PNLビュー

- **チャート**：アカウントの**価値**と**PNL**を切り替え、**パーペチュアル**または**合算**を対象に、24時間、7日、30日、累計で表示します。
- **カレンダー**：日次の損益ヒートマップ。各日はその日の損益の大きさに応じて緑または赤で塗られ、ツールチップにPNLとROEが表示されます。
- **PNLカレンダー**：月単位のビューで、履歴を遡ってページ送りできます。日数ベースの最長プラス連続記録も表示されます。

## ポジション、注文、履歴

| タブ | 内容 |
| --- | --- |
| ポジション | エントリー、マーク、PNL、ROE付きのオープンポジション |
| 残高 | スポットトークン残高 |
| 注文 | オープン注文 |
| 約定 | 直近の注文執行 |
| トレード | 完了した取引。結果、サイド、資産、想定元本、サイズで絞り込めます |
| TWAP | 有効および約定済みの[TWAP](/jp/orders/twap)注文 |
| 振替 | 入出金履歴 |
| パフォーマンス | ベストトレードと資産別のパフォーマンス内訳 |
| コピートレード | コピートレードウォレット。実行中、停止、アーカイブ済みで絞り込めます |

任意のポジションやPNLは、テーブルから直接イメージカードとして共有できます。

## 資金配分

コピートレードウォレットが複数のトレーダーをフォローしている場合、配分エディターでその資金をトレーダー間に配分します。**均等**分割、またはトレーダーごとの**カスタム**ウェイトスライダーです。配分の合計は100%になる必要があり、フォロー中の各トレーダーには0%を超えるシェアが必要です。セットアップの全体像は[コピートレーディング](/jp/copy-trade)を参照してください。

<Note>
  プロフィールには手数料ティアの進捗、紹介リンク、キャッシュバックの統計も表示されます。[手数料、紹介、リワード](/jp/fees-referrals-rewards)を参照してください。
</Note>
