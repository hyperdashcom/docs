排行榜按净已实现盈亏为交易者排名，让您找到真正在赚钱的人、他们活跃的市场以及对应的时间范围。前三名登上领奖台，佩戴金、银、铜徽章；您自己的一行会固定显示并带有 **You** 徽章，让您随时知道自己的位置。

## 排名与时间范围

- **市场标签**：总榜、股票、大宗商品、主流币（BTC、ETH、HYPE、SOL 永续）和山寨币，外加一个资产筛选器，可将任意标签收窄到单一市场。
- **时间范围**：24H、7D、30D、YTD 和全部时间。
- **盈亏显示**：净盈亏可在美元和百分比之间切换。百分比模式显示净盈亏相对该交易者账户价值的比例。

## 读懂表格

| 列 | 含义 |
| --- | --- |
| 排名 | 在当前市场标签和时间范围内的名次 |
| 交易者 | 名称或地址，悬停显示快捷操作 |
| 账户价值 | 当前总权益 |
| 净盈亏 | 所选时间范围内的净已实现盈亏，以 \$ 或 % 计 |
| 成交量 | 交易量 |
| 胜率 | 盈利交易占比 |
| 交易数 | 交易笔数 |
| 主要资产 | 按历史成交量计交易最多的资产 |

数字列均可排序。

## 筛选与搜索

可按账户价值范围、胜率范围或交易风格标签（算法、剥头皮、日内、波段）筛选。搜索可按名称查找交易者，粘贴任意 0x 地址即可直接查询该交易者，即使其不在已加载的排名中。

## 在这里可以做什么

<Steps>
  <Step title="打开交易者主页">
    点击任意行即可预览该交易者的完整主页：绩效统计、盈亏图表和日历、持仓和交易历史，与[投资组合与分析](/cn/portfolio-analytics)中描述的视图相同。
  </Step>
  <Step title="追踪、复制或 Snoop">
    悬停在交易者上可使用快捷操作：**追踪**将该钱包加入您的追踪钱包，**复制**复制其地址，**Snoop** 在您的终端上实时跟随其动态。
  </Step>
  <Step title="开始跟单">
    在交易者主页上，跟单评分板块包含一个跟单按钮，可直接打开设置流程。参见[跟单交易](/cn/copy-trade)。
  </Step>
</Steps>

<Note>
  排名基于净已实现表现计算，因此持仓上的未实现盈亏不会使交易者在榜单上升降。
</Note>
