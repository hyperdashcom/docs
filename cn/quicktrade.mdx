快捷交易是为快速行情打造的一键交易：两排预设金额按钮（买入在上、卖出在下），按下的瞬间即发送订单，无需操作订单表单。它以**快捷交易**小组件的形式提供，可从小组件抽屉（工具类别）添加到您的布局；当您点击新闻小组件中头条上的 ticker 标签时，同样的按钮也会内嵌显示。快捷交易仅支持永续市场，包括 [xyz markets](/cn/markets-assets)；不支持现货。

## 使用方式

<Steps>
  <Step title="关联市场">
    添加快捷交易小组件并将其关联到一个永续市场。小组件顶部显示实时标记价、24 小时涨跌幅、杠杆控制和当前订单类型。
  </Step>
  <Step title="设置金额和订单类型">
    点击小组件上的齿轮打开设置，选择三个按钮金额、订单类型，以及杠杆和确认行为。所有更改立即保存：登录时保存到您的账户，同时始终保存到您的浏览器。
  </Step>
  <Step title="下单">
    按下买入或卖出行的金额按钮。开启确认时，一个锚定在该按钮上的弹窗会汇总市场、方向、金额和订单类型：确认即发送，按 Escape 或点击其他位置即取消。勾选**不再询问**即可实现真正的一键交易。
  </Step>
</Steps>

每次按下都会发送一笔独立订单，因此快速连续点击会并行执行：订单在途时按钮从不锁定。

## 设置

| 参数 | 说明与选项 | 默认值 |
| --- | --- | --- |
| 按钮金额 | 买卖两行共用的三个 USD 金额，每个 \$10 到 \$10,000,000 | \$100、\$1,000、\$10,000 |
| 金额含义 | **名义价值**：\$10,000 按钮开立 \$10,000 的仓位。**保证金**：\$10,000 按钮花费 \$10,000 的保证金，仓位大小为保证金乘以杠杆。 | 名义价值 |
| 订单类型 | [市价](/cn/orders/market)、中间价限价（在中间价挂一笔[限价单](/cn/orders/limit)）、[追价](/cn/orders/chase)或[蜂群](/cn/orders/swarm) | 市价 |
| 最大滑点 | 仅市价单：相对中间价的最大滑点，最高 50% | 1% |
| 分片数 | 仅蜂群：分片数量，2 到 200 | 5 |
| 激进度 | 仅蜂群：1 到 5 | 3 |
| 不规则分片 | 仅蜂群：使分片数量各不相同，拆分不那么均匀 | 关 |
| 始终使用最大杠杆 | 下单前将该市场调至其最大杠杆。关闭时，订单使用您已为该市场设置的杠杆。在小组件中手动选择杠杆会关闭此项。 | 关 |
| 下单前确认 | 发送任何订单前显示订单摘要弹窗 | 开 |

## 常见问题

<AccordionGroup>
  <Accordion title="快捷交易支持哪些市场？">
    仅永续市场，包括 xyz markets（股票、指数、大宗商品、外汇）。不支持现货市场。
  </Accordion>

  <Accordion title="最小下单金额是多少？">
    每笔订单名义价值 \$10。蜂群至少需要 \$20 的名义价值，才能拆分为两个分片。
  </Accordion>

  <Accordion title="无法应用最大杠杆时会怎样？">
    按名义价值计算时，订单仍会以您当前的杠杆发送，并给出警告。按保证金计算时，订单会被取消，因为仓位大小依赖于设置失败的杠杆。
  </Accordion>

  <Accordion title="我的设置会跨设备同步吗？">
    登录时，设置保存到您的账户。它们同时镜像在您的浏览器中，因此刷新后仍然有效，在该设备上未登录时也能使用。
  </Accordion>
</AccordionGroup>

<Note>
  关闭确认后，按下按钮即立即发送订单，且无法撤销。在金额和订单类型调整到位前，请保持**下单前确认**开启。
</Note>
