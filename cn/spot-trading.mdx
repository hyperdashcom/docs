---
title: "现货交易"
description: "在以 USDC 计价、结算到您钱包的现货市场上直接买卖资产。"
---

在 Hyperdash 上进行现货交易，意味着买卖资产本身，而不是与其价格挂钩的合约。所有现货市场均以 USDC 计价、24/7 交易，买到的就是您拥有的：现货买入在链上结算到您的钱包，可以发送或转出。

## 现货余额如何运作

- 买入从您的现货 USDC 余额中扣款。卖出使用您持有的代币余额：您只能卖出自己拥有的数量。
- 被挂单占用的余额显示为占用状态，在该订单成交或取消前无法被其他订单使用。
- 交易面板显示您的可用 USDC 和可用代币余额，并提供**充值**和**永续转现货**快捷入口。USDC 可通过划转弹窗在您的永续和现货账户之间自由划转（统一账户共享同一余额，可跳过这一步）。
- 您的持有资产显示在余额表中，包括数量、可用、价值、入场价和盈亏，以及**发送**、**转账**或为持有资产设置 TP/SL 的操作。

## 下现货订单

<Steps>
  <Step title="选择现货市场">
    在资产选择器中选择一个现货交易对，例如 HYPE/USDC。
  </Step>
  <Step title="选择订单类型">
    市价和限价是顶层标签。**高级**下拉菜单增加阶梯、追价、TWAP、追价 TWAP 和蜂群，以及条件类型止损限价和止损市价。
  </Step>
  <Step title="设置方向和数量">
    选择买入或卖出，然后以代币或 USD 计设置数量，或使用滑块按可用余额的百分比设置。面板会显示订单价值、估算滑点，以及您的挂单（maker）和吃单（taker）费率。
  </Step>
  <Step title="提交">
    市价和限价买单可以先附加止盈和止损触发单，按价格或按 % 或 \$ 计的收益和亏损设置。TP/SL 离场以市价单执行。
  </Step>
</Steps>

每种订单类型都有专属参考页面：从[订单类型总览](/cn/orders/overview)开始，或直接跳转到[市价](/cn/orders/market)、[限价](/cn/orders/limit)、[阶梯](/cn/orders/scale)、[止损限价](/cn/orders/stop-limit)、[止损市价](/cn/orders/stop-market)、[追价](/cn/orders/chase)、[TWAP](/cn/orders/twap)、[追价 TWAP](/cn/orders/chase-twap) 或[蜂群](/cn/orders/swarm)。

## 设置

| 参数 | 说明与选项 | 默认值 |
| --- | --- | --- |
| 最大滑点 | 限制现货市价类成交对您不利的最大幅度。点击订单表单中的 **Est / Max** 滑点读数进行调整。 | 8% |
| 止盈 / 止损 | 市价和限价买单可选。按价格触发，或按 % 或 \$ 计的收益和亏损触发。 | 关 |

最小订单价值为 \$10。会拆分为多笔订单的订单类型（如阶梯、TWAP 和蜂群）要求每笔子订单同样满足该最低值。

## 现货 vs 永续

| | 现货 | 永续 |
| --- | --- | --- |
| 所有权 | 您拥有资产，结算到您的钱包 | 仅合约敞口 |
| 方向 | 买入，或卖出您持有的数量 | 做多或做空 |
| 杠杆 | 无；订单全额出资 | 因市场而异 |
| 资金费率 | 无 | 每小时计提 |
| 强平 | 无 | 杠杆仓位可能发生 |

## 常见问题

<AccordionGroup>
  <Accordion title="现货可以做空吗？">
    不可以。现货卖出以您持有的余额为限。如需做空敞口，请使用永续市场：参见[交易指南](/cn/trading-guide)。
  </Accordion>

  <Accordion title="如何为现货余额充值？">
    直接充值，或使用**永续转现货**按钮从永续账户划转 USDC。参见[入门与存款](/cn/onboarding-deposits)。
  </Accordion>

  <Accordion title="现货交易需要支付资金费率吗？">
    不需要。资金费率仅适用于永续合约。现货成本为订单表单中显示的挂单和吃单费率；参见[费用、邀请与奖励](/cn/fees-referrals-rewards)。
  </Accordion>

  <Accordion title="可以为已持有的代币设置 TP/SL 吗？">
    可以。使用余额表中的 TP/SL 操作，为现有持仓附加止盈或止损触发单。
  </Accordion>
</AccordionGroup>

<Note>
  被挂单占用的代币处于占用状态：在订单成交或取消前无法卖出或发送。当现有订单已占用部分余额时，面板会发出提醒。
</Note>
