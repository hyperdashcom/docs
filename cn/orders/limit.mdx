---
title: "限价单"
description: "将订单挂在订单簿上，只以您选定的价格或更优价格成交。"
---

限价单只会以您设定的价格或更优的价格执行：买入以您的限价或更低价格成交，卖出以您的限价或更高价格成交。您掌控价格，代价是不保证成交。

## 下单机制

- 以您的限价挂出单笔订单，直到取消前有效（GTC）：订单会持续生效，直到成交或被您取消。
- 如果您的价格偏离市场，订单会留在订单簿上，直到价格到达。
- 如果您的价格穿越市场（买价高于最优卖价，或卖价低于最优买价），订单会立即以更优的可得价格执行。
- 可能部分成交，且不存在滑点：您的限价就是您可能拿到的最差价格。

## 适用场景

- 您想要价格确定性，并愿意等待市场向您靠近。
- 您在下跌中挂买单或在上涨中挂卖单，无需盯盘。
- 您想在一张订单里设置入场，并同时附加止盈和止损。

## 参数

| 参数 | 说明与选项 | 默认值 |
| --- | --- | --- |
| 限价 (USD) | 您能接受的最差价格。点击**中间价**可预填当前中间价。 | 无 |
| 数量 | 以资产或 USD 计，可用滑块按当前杠杆下可用保证金的百分比设置数量。 | 无 |
| 止盈 / 止损（可选） | 按价格或按收益和亏损百分比附加止盈和止损触发单。 | 关 |
| 只减仓（可选） | 持有仓位时显示。订单只能减少仓位，不能增加或反向。 | 关 |

面板会显示强平价、订单价值、所需保证金和费用。最小订单价值为 \$10。

## 示例

BTC 价格为 \$118,400。您在 \$116,000 挂出 0.1 BTC 的限价买单：订单价值 \$11,600，10 倍杠杆下所需保证金 \$1,160。如果 BTC 下跌穿过 \$116,000，您将以 \$116,000 或更优价格成交。如果价格始终没有到达，订单会一直保持挂出状态，直到您取消。

<Note>
  高于当前价格的限价买单（或低于当前价格的限价卖单）是可即时成交的：它会像市价单一样立即开始成交，但以您的限价为上限。
</Note>
