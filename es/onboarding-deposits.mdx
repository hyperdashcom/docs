## Iniciar sesión

Puedes iniciar sesión con:

- Google
- Apple
- Correo electrónico
- Cualquier billetera compatible con EVM

Si inicias sesión con Google, Apple o correo electrónico, Hyperdash genera una billetera no custodial para ti, asegurada por Turnkey, y depositas en esa billetera para operar. La autenticación de dos factores está disponible en tu cuenta una vez que has iniciado sesión.

## Depósitos

El modal de depósito agrupa todo en tres pestañas: **Todos**, **Cripto** y **Efectivo**. Elige una moneda y un método, y Hyperdash muestra el tiempo de liquidación y cualquier mínimo antes de confirmar.

### Cripto

- **Cripto**: envía desde cualquier billetera o exchange. Las redes compatibles son Ethereum, Arbitrum, Base, Optimism, Polygon, BSC, Solana, Bitcoin, Tron, HyperEVM y Hyperliquid.
- Elige **Solo depositar** para conservar el activo que enviaste, o **Convertir a USDC** para que se convierta al llegar.
- **Exchanges**: deposita directamente desde una cuenta de exchange conectada. Se admiten Binance, Coinbase, Bybit, KuCoin, Gate, Bitfinex y BtcTurk.

### Enviar a la red correcta

Las direcciones de depósito son específicas de cada red. La dirección que aparece en el modal de depósito solo acepta el activo y la red que se muestran encima.

<Warning>
  Los activos enviados por la red equivocada, a una dirección copiada de otra cadena o en un token no compatible se pierden de forma permanente. Hyperdash no puede revertirlos, recuperarlos ni reembolsarlos. Los depósitos son transferencias on-chain a tu propia billetera no custodial, así que una vez que la transacción se transmite nadie puede deshacerla. Es tu responsabilidad confirmar la red, la dirección y el activo antes de enviar.
</Warning>

Antes de enviar:

- Confirma que la red coincide. Las direcciones de Ethereum, Arbitrum, Base, Optimism, Polygon, BSC y HyperEVM son idénticas en apariencia, pero no son intercambiables.
- Envía solo el activo indicado para esa dirección.
- Cumple el depósito mínimo que se muestra en el modal. Los importes menores podrían no acreditarse.
- Envía primero una cantidad pequeña de prueba si es tu primer depósito desde una billetera o un exchange nuevo.

### Efectivo

| Método | Cómo funciona | Monedas |

| Transferencia bancaria | Una cuenta virtual a tu propio nombre, para que puedas transferir desde tu banco. La disponibilidad depende de tu país. | Todas las monedas admitidas |

| PayPal | Paga desde tu saldo de PayPal o una cuenta vinculada. | EUR |

| PIX | El sistema de pagos instantáneos de Brasil. | BRL |
| SPEI | El sistema de transferencias interbancarias de México. | MXN |
| BLIK | El sistema de pagos móviles de Polonia. | PLN |
| UPI | El sistema de pagos instantáneos de India. | INR |
| Interac | Transferencia bancaria canadiense mediante Interac. | CAD |

### Monedas admitidas

Hyperdash acepta depósitos en 34 monedas fiat:

AUD, BGN, BRL, CAD, CHF, CLP, COP, CZK, DKK, EUR, GBP, HKD, HUF, IDR, ILS, INR, JPY, KRW, MXN, MYR, NOK, NZD, PEN, PHP, PLN, RON, SEK, SGD, THB, TRY, USD, VND, ZAR, ZMW

No todos los métodos admiten todas las monedas. El modal de depósito solo muestra los métodos disponibles para la moneda que elijas y oculta lo que no esté disponible en tu país.

<Note>
  Los depósitos están restringidos en jurisdicciones sancionadas, y la cobertura de transferencia bancaria es más limitada que la de los demás métodos. Si un método no aparece, no está disponible para tu país o para la moneda seleccionada.
</Note>

Una vez que se liquide un depósito, podrás ver el saldo en tu cuenta y usar todas las funciones de Hyperdash.

## Importar una Billetera

Las cuentas existentes de Hyperliquid se pueden importar y operar a través de su clave API en solo unos clics:

- Conectar Billetera: Conecta una billetera con una cuenta de Hyperliquid asociada.
- Aprobar Agente: Genera una clave API de Hyperliquid para operar.
- Aprobar Builder: Habilita la operación en Hyperdash.
