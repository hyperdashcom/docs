Hyperdash는 에이전트 API 지갑을 통해 거래를 실행합니다. 본인 지갑이 자신을 대신해 주문에 서명하도록 승인한 별도의 트레이딩 키입니다. 덕분에 주문마다 지갑에서 확인하지 않고 거래할 수 있으며, 출금과 이체에는 여전히 본인 지갑의 서명이 필요합니다.

## 에이전트 지갑의 작동 방식

<Steps>
  <Step title="지갑 연결 또는 생성">
    터미널 지갑 설정에서 기존 지갑을 연결하거나 Turnkey로 보호되는 새 논커스터디얼 지갑을 만듭니다. [온보딩, 입금 및 지갑](/ko/onboarding-deposits)을 참고하세요.
  </Step>
  <Step title="에이전트 승인">
    Hyperdash가 브라우저에서 새 키페어를 생성하고, 본인 지갑이 이를 트레이딩 에이전트로 등록하는 승인에 서명합니다. 에이전트 키는 180일간 유효하며 저장 전에 브라우저에서 암호화됩니다.
  </Step>
  <Step title="빌더 승인">
    두 번째 서명으로 Hyperdash에서의 거래가 활성화됩니다. 이후 자동화된 [주문 유형](/ko/orders/overview)을 포함해 내가 내는 모든 주문은 에이전트 키로 서명됩니다.
  </Step>
</Steps>

**에이전트 매니저**는 에이전트의 주소와 만료일을 활성, 30일 내 만료, 곧 만료, 만료됨 상태와 함께 보여주며, **에이전트 키 갱신** 동작도 제공합니다.

## 보안 FAQ

<AccordionGroup>
  <Accordion title="에이전트 지갑은 무엇을 할 수 있고 무엇을 할 수 없나요?">
    에이전트 키는 트레이딩 동작에만 서명합니다. 주문의 생성, 수정, 취소입니다. 출금과 자산 이체는 에이전트가 아니라 언제나 본인 지갑이 서명합니다.
  </Accordion>

  <Accordion title="키는 누가 보관하나요?">
    지갑의 프라이빗 키는 절대 지갑을 떠나지 않습니다. 에이전트 승인과 출금 서명은 본인이 직접 합니다. Hyperdash를 통해 생성된 지갑은 논커스터디얼이며 Turnkey로 보호됩니다. 에이전트 키는 브라우저에서 생성되어 저장 전에 그곳에서 암호화되며, 이것이 [카피트레이딩](/ko/autotrade) 같은 기능을 가능하게 합니다.
  </Accordion>

  <Accordion title="에이전트를 갱신하거나 해지하려면 어떻게 하나요?">
    에이전트 매니저를 열고 **에이전트 키 갱신**을 사용하세요. 완전히 새로운 키가 기존 키를 대체합니다. 원래 지갑이 연결되어 있어야 하며, 다른 주소에서의 갱신은 앱이 차단합니다. 지갑 설정을 다시 실행해도 새 에이전트를 승인하기 전에 이전 Hyperdash 에이전트가 먼저 해지됩니다.
  </Accordion>

  <Accordion title="에이전트가 만료되면 어떻게 되나요?">
    에이전트 키는 180일간 유효합니다. 만료된 키는 더 이상 주문에 서명할 수 없으므로, 계속 거래하려면 에이전트 매니저에서 갱신하세요.
  </Accordion>

  <Accordion title="어떤 로그인 방법이 지원되나요?">
    Google, Apple, 이메일 매직 링크, 지갑 로그인입니다. 지갑 로그인은 메시지 서명만 요청합니다. 무료이며 트랜잭션이 전송되지 않습니다.
  </Accordion>

  <Accordion title="2단계 인증은 어떻게 설정하나요?">
    설정의 보안에서 패스키(생체 인증 또는 보안 키) 또는 인증 앱 중 하나를 활성화하세요. 인증 앱 설정은 QR 코드 또는 설정 키를 보여주고 6자리 코드를 확인한 뒤, 다운로드할 수 있는 일회용 백업 코드를 발급합니다. 인증 앱을 활성화하려면 먼저 패스키를 제거해야 합니다.
  </Accordion>

  <Accordion title="2단계 인증은 언제 요구되나요?">
    로그인 후(기기를 30일간 신뢰하는 옵션 포함), 그리고 자금을 출금하기 전에 다시 요구됩니다. 2FA 기기를 분실한 경우 백업 복구 코드를 각각 한 번씩 사용할 수 있습니다.
  </Accordion>
</AccordionGroup>

<Note>
  인증 앱을 활성화할 때 백업 복구 코드를 저장해 두세요. 2FA 기기를 잃어버리고 코드도 없다면 계정 접근 권한을 영구히 잃을 수 있습니다.
</Note>
