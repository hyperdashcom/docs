---

Perp RFQ（見積依頼）は、機関投資家グレードの流動性をオンデマンドでHyperdashにもたらします。大口注文を見えている板で少しずつ執行する代わりに、ホワイトリスト登録されたマーケットメーカーに見積を依頼し、彼らがリアルタイムで競って価格を提示します。より大きなサイズ、より良い執行、より良い価格です。

RFQは株式、コモディティ、暗号資産にわたる35以上の市場で利用できます。

<Note>
  Perp RFQは現在招待制です。[アクセスをリクエスト](https://hyperdash.com/rfq)すると、当社チームが利用資格を確認します。
</Note>

## RFQの仕組み

<Steps>
  <Step title="リクエストを送信する">
    トレードパネルの**RFQ**タブを開き、市場を選んで、サイズをUSDC建てまたは資産建てで指定します。買い/ロングまたは売り/ショートを選択します。**売買方向を公開する**にチェックを入れない限り、方向はマーケットメーカーに開示されません。
  </Step>
  <Step title="マーケットメーカーが応答する">
    ホワイトリスト登録されたマーケットメーカーはリクエストの市場とサイズを受け取り、**5秒**以内に見積を提示するか見送ります。応答したマーケットメーカーは、公開のオーダーブックに実際の流動性を直接追加します。
  </Step>
  <Step title="見積を確認する">
    RFQチケットには、届いた見積が順次表示され、更新された推定スリッページ、平均執行価格、RFQ前の板と比較した改善幅も確認できます。
  </Step>
  <Step title="取引するか、見送るか">
    執行の猶予は**30秒**です。確定するまで何も取引されず、リクエストのキャンセルも、そのまま失効させることもいつでも可能です。
  </Step>
</Steps>

## 主要パラメータ

| パラメータ | 値 |
| --- | --- |
| 最大注文サイズ | リクエストあたり想定元本 \$500,000 |
| 見積ウィンドウ | 30秒、経過するとリクエストは失効 |
| マーケットメーカーの応答時間 | 見積または見送りまで5秒 |
| サイズ入力 | USDC想定元本または原資産数量 |
| 方向 | デフォルトでマーケットメーカーに非公開、任意で公開可能 |
| アクセス | 招待制 |

## FAQ

<AccordionGroup>
  <Accordion title="アクセスを取得するには？">
    Perp RFQは招待制です。[アクセスをリクエスト](https://hyperdash.com/rfq)すると、当社チームが利用資格を確認します。
  </Accordion>

  <Accordion title="マーケットメーカーには何が見えますか？">
    リクエストの市場とサイズです。**売買方向を公開する**を有効にしない限り、取引の方向は非公開のままです。
  </Accordion>

  <Accordion title="方向を公開する意味はありますか？">
    公開すると、マーケットメーカーは両サイドではなく片側だけに価格を付ければよくなるため、提示価格がタイトになる可能性があります。非公開にすれば意図を悟られずに済みます。リクエストごとに選択できます。
  </Accordion>

  <Accordion title="リクエストしたら必ず取引しなければなりませんか？">
    いいえ。見積に拘束力はありません。執行するかどうかはあなたが選び、何もしなければリクエストは30秒後にそのまま失効します。
  </Accordion>

  <Accordion title="RFQに追加費用はかかりますか？">
    かかりません。RFQの利用に追加手数料はありません。執行された注文には通常のHyperdash取引手数料が適用されます。
  </Accordion>

  <Accordion title="どのマーケットメーカーも見積を出さなかったらどうなりますか？">
    リクエストは30秒後に失効し、何も執行されません。新しいリクエストはいつでも送信できます。
  </Accordion>
</AccordionGroup>
