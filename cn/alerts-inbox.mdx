收件箱是 Hyperdash 的通知中心。它将平台公告、系统通知、警报、奖励和里程碑更新以及私信汇集在一个面板中，并在您交易时实时更新。

## 收件箱在哪里

点击页头右上角的铃铛图标即可打开收件箱。有未读内容时，铃铛会显示橙色圆点，面板内会显示未读数量。三个标签用于筛选视图：**全部**、**消息**和**警报**。

## 收件箱里有什么

| 类型 | 涵盖内容 |
| --- | --- |
| 公告 | 面向所有用户广播的产品和平台新闻 |
| 系统通知 | 直接发送给您的账户级通知 |
| 警报 | 可能需要您注意的提醒 |
| 里程碑 | 成就通知 |
| 奖励到账 | 奖励进入您账户时的确认 |
| VIP 邀请 | VIP 计划的邀请 |
| 私信 | 与其他 Hyperdash 用户的一对一对话 |

通知可以包含一个按钮，直接跳转到相关页面。

## 运作方式

- 收件箱通过实时连接保持在线，因此即使面板关闭，未读角标也会更新。
- 打开收件箱会将公告和系统通知标记为已读。私信在您打开其对话时才标记为已读。
- 私信支持在对话视图中回复。公告和系统频道为只读。
- 收件箱底部的**联系我们**按钮会打开反馈表单。

## 追踪钱包的警报

您关注的钱包的动态不会进入收件箱，而是流入交易终端的实时**追踪**信息流：包括方向、数量和价格的交易，以及充值和提现等账户事件。信息流可按列表、方向、开仓或平仓以及名义价值筛选。要开始关注某个钱包，参见[交易者探索](/cn/wallet-explore)。

<Note>
  收件箱仅在登录 Hyperdash 后可用。
</Note>

## 常见问题

<AccordionGroup>
  <Accordion title="应用之外也能收到通知吗？">
    收件箱是主要渠道。Hyperdash 公告也可能通过电子邮件送达，您可以随时退订。此外，Hyperdash 还在 Telegram 上运营公开的鲸鱼警报频道，入口在应用页头。
  </Accordion>

  <Accordion title="我关注的交易者有动作时如何收到提醒？">
    在[交易者探索](/cn/wallet-explore)中追踪该钱包。其成交和账户事件会实时出现在追踪信息流中。
  </Accordion>

  <Accordion title="我的未读角标为什么消失了？">
    打开收件箱即视为已读公告和系统通知，因为它们的完整内容会直接显示在列表中。私信的未读计数会保留，直到您打开对话。
  </Accordion>

  <Accordion title="可以回复通知吗？">
    公告和系统通知为只读。来自其他 Hyperdash 用户的私信可以直接在对话视图中回复。
  </Accordion>
</AccordionGroup>
