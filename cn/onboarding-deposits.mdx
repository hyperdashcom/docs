## 登录

您可以通过以下方式登录：

- Google
- Apple
- 电子邮件
- 任何兼容 EVM 的钱包

使用 Google、Apple 或电子邮件登录时，Hyperdash 会为您生成一个由 Turnkey 保护的非托管钱包，您向该钱包充值即可交易。登录后可在账户中启用双重验证。

## 存款

存款弹窗将所有方式归为三个标签页：**全部**、**加密货币**和**现金**。选择币种和方式后，Hyperdash 会在您确认前显示到账时间和任何最低限额。

### 加密货币

- **加密货币**：可从任意钱包或交易所转入。支持的网络包括 Ethereum, Arbitrum, Base, Optimism, Polygon, BSC, Solana, Bitcoin, Tron, HyperEVM 和 Hyperliquid。
- 选择**仅存入**以保留您转入的资产，或选择**兑换为 USDC** 让其在到账时自动兑换。
- **交易所**：直接从已连接的交易所账户存入。支持 Binance, Coinbase, Bybit, KuCoin, Gate, Bitfinex 和 BtcTurk。

### 发送到正确的网络

存款地址与网络一一对应。存款弹窗中显示的地址仅接收其上方所示的资产和网络。

<Warning>
  通过错误网络发送、发送到从其他链复制的地址，或发送不受支持的代币，资产将永久丢失。Hyperdash 无法撤销、找回或退还这些资产。存款是转入您自己的非托管钱包的链上转账，交易一旦广播，任何人都无法撤回。发送前确认网络、地址和资产是您的责任。
</Warning>

发送前：

- 确认网络一致。Ethereum, Arbitrum, Base, Optimism, Polygon, BSC 和 HyperEVM 上的地址看起来完全相同，但彼此并不通用。
- 仅发送该地址所示的资产。
- 满足弹窗中显示的最低存款额。低于该金额可能不会到账。
- 如果是首次从新的钱包或交易所存入，请先发送一笔小额测试。

| 银行卡 | Visa 和 Mastercard，包含 Apple Pay 与 Google Pay。Hyperdash 会比较多家支付服务商的实时报价，便于您选择最优汇率。 | 所有支持的币种 |

| CashApp | 使用您的 CashApp 余额支付。 | USD |

### 支持的币种

Hyperdash 支持以 34 种法币存款：

AUD, BGN, BRL, CAD, CHF, CLP, COP, CZK, DKK, EUR, GBP, HKD, HUF, IDR, ILS, INR, JPY, KRW, MXN, MYR, NOK, NZD, PEN, PHP, PLN, RON, SEK, SGD, THB, TRY, USD, VND, ZAR, ZMW

并非所有方式都支持所有币种。存款弹窗只会显示所选币种可用的方式，并隐藏在您所在国家或地区不可用的选项。

<Note>
  受制裁地区无法存款，且银行转账的覆盖范围比其他方式更窄。如果某种方式未显示，说明它在您所在的国家或地区、或对所选币种不可用。
</Note>

存款到账后，您即可在账户中查看余额并使用 Hyperdash 的全部功能。

## 导入钱包

现有的 Hyperliquid 账户可以通过 API 密钥导入并进行交易，只需几步操作：

- 连接钱包：连接具有关联 Hyperliquid 账户的钱包。
- 批准代理：生成用于交易的 Hyperliquid API 密钥。
- 批准构建者：启用在 Hyperdash 上的交易。
