---
title: "止损限价"
description: "在止损价触发一笔限价单，并对您能接受的最差价格设置硬性界限。"
---

止损限价单会等待市场到达您的止损价，然后按您的限价挂出一笔限价单。触发前不会有任何成交，触发后订单只以限价或更优价格成交。

## 下单机制

- 提交时不执行任何交易。订单会等待资产价格到达您的止损价。
- 开启**隐匿**（默认）时，由 Hyperdash 基础设施监控价格，仅在触发后才下单，在此之前订单保持隐藏。关闭隐匿时，止损单会作为触发订单公开挂在链上。
- 触发时，一笔按您限价的限价单被送入订单簿，并以该价格或更优价格成交。
- 不保证完成：如果价格跳空越过您的限价，订单会保持未成交状态，直到价格回落或您取消。

## 适用场景

- 交易突破：只在价位真正突破后，在阻力位上方买入或支撑位下方卖出。
- 为最差成交价设置上限，而不是接受市价单拿到的任何价格。
- 在明确的触发位带价格控制地离场。开启**只减仓**，让订单只能平掉您的仓位。

## 参数

| 参数 | 说明与选项 | 默认值 |
| --- | --- | --- |
| 止损价 (USD) | 触发价格：买入时高于当前价，卖出时低于当前价。 | 无 |
| 限价 | 触发时挂出的限价单价格。 | 当前价格 |
| 数量 | 以资产或 USD 计。最小订单价值 \$10。 | 无 |
| 只减仓（可选） | 订单只能减少现有仓位。 | 关 |
| 隐匿（可选） | 将止损单路由到 Hyperdash 基础设施，触发前不进入订单簿。 | 开 |

## 示例

BTC 价格为 \$117,400，您想在突破 \$120,000 时买入。您设置一笔止损限价单：止损价 \$120,000，限价 \$120,250，数量 0.5 BTC。当 BTC 触及 \$120,000 时，一笔 \$120,250 的限价买单被挂出，并以该价格或更优价格成交。如果 BTC 直接跳空到 \$120,600，订单会停留在 \$120,250 未成交。

<Note>
  止损限价用成交风险换取价格风险：请根据市场波动性设置止损价与限价之间的间距，避免一次快速行情同时跳过两个价位。当执行比价格更重要时，请使用[止损市价](/cn/orders/stop-market)。
</Note>
