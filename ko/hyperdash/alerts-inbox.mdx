인박스는 Hyperdash의 알림 센터입니다. 플랫폼 공지, 시스템 안내, 경고, 리워드 및 마일스톤 업데이트, 다이렉트 메시지를 하나의 패널에 모으며, 거래하는 동안 실시간으로 업데이트됩니다.

## 인박스의 위치

헤더 우측 상단의 종 아이콘을 클릭해 인박스를 엽니다. 읽지 않은 항목이 있으면 종에 주황색 점이 표시되고, 패널 안에 읽지 않은 개수가 나타납니다. **전체**, **메시지**, **알림** 세 개의 탭으로 보기를 필터링합니다.

## 인박스에 도착하는 것

| 유형 | 다루는 내용 |
| --- | --- |
| 공지 | 모든 사용자에게 전달되는 제품 및 플랫폼 소식 |
| 시스템 알림 | 나에게 직접 전송되는 계정 수준 안내 |
| 경고 | 주의가 필요할 수 있는 알림 |
| 마일스톤 | 달성 알림 |
| 리워드 지급 | 리워드가 계정에 들어왔을 때의 확인 |
| VIP 초대 | VIP 프로그램 초대 |
| 다이렉트 메시지 | 다른 Hyperdash 사용자와의 일대일 대화 |

알림에는 관련 페이지로 바로 이동하는 버튼이 포함될 수 있습니다.

## 작동 방식

- 인박스는 실시간 연결로 유지되므로, 패널이 닫혀 있어도 읽지 않음 배지가 업데이트됩니다.
- 인박스를 열면 공지와 시스템 안내가 읽음으로 표시됩니다. 다이렉트 메시지는 해당 스레드를 열 때 읽음 처리됩니다.
- 다이렉트 메시지는 스레드 화면에서 답장할 수 있습니다. 공지 및 시스템 채널은 읽기 전용입니다.
- 인박스 하단의 **문의하기** 버튼은 피드백 폼을 엽니다.

## 추적 지갑 알림

팔로우하는 지갑의 활동은 인박스로 가지 않습니다. 트레이딩 터미널의 실시간 **추적** 피드로 스트리밍됩니다. 방향, 수량, 가격이 포함된 거래와 입출금 같은 계정 이벤트입니다. 피드는 목록, 방향, 진입 또는 종료, 명목 규모로 필터링할 수 있습니다. 지갑 팔로우를 시작하려면 [트레이더 탐색](/ko/hyperdash/wallet-explore)을 참고하세요.

<Note>
  인박스는 Hyperdash에 로그인한 상태에서만 사용할 수 있습니다.
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="앱 밖에서도 알림을 받을 수 있나요?">
    인박스가 기본 채널입니다. Hyperdash 공지는 이메일로도 도착할 수 있으며 언제든 수신을 해제할 수 있습니다. 또한 Hyperdash는 앱 헤더에서 연결되는 공개 고래 알림 텔레그램 채널을 운영합니다.
  </Accordion>

  <Accordion title="팔로우하는 트레이더가 움직일 때 어떻게 알림을 받나요?">
    [트레이더 탐색](/ko/hyperdash/wallet-explore)에서 지갑을 추적하세요. 그들의 체결과 계정 이벤트가 추적 피드에 실시간으로 나타납니다.
  </Accordion>

  <Accordion title="읽지 않음 배지가 왜 사라졌나요?">
    공지와 시스템 안내는 전체 내용이 목록에 표시되므로, 인박스를 여는 것만으로 읽음 처리됩니다. 다이렉트 메시지는 스레드를 열 때까지 읽지 않음 개수가 유지됩니다.
  </Accordion>

  <Accordion title="알림에 답장할 수 있나요?">
    공지와 시스템 안내는 읽기 전용입니다. 다른 Hyperdash 사용자의 다이렉트 메시지에는 스레드 화면에서 바로 답장할 수 있습니다.
  </Accordion>
</AccordionGroup>
