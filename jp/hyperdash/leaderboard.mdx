リーダーボードはトレーダーをネット実現PNLでランク付けし、誰が実際に、どの市場で、どの期間で成果を出しているかを見つけられます。上位3人はゴールド、シルバー、ブロンズのバッジで表彰台に立ち、自分の行は**あなた**バッジ付きでピン留めされるので、自分の順位を常に確認できます。

## ランキングとタイムフレーム

- **マーケットタブ**：Overall、Equities、Commodities、Majors（BTC、ETH、HYPE、SOLのパープ）、Altsに加えて、任意のタブを単一市場に絞り込むアセットフィルター。
- **タイムフレーム**：24H、7D、30D、YTD、All Time。
- **PNL表示**：ネットPNLをドルとパーセントで切り替えできます。パーセントモードでは、トレーダーの口座価値に対するネットPNLが表示されます。

## テーブルの読み方

| 列 | 意味 |
| --- | --- |
| Rank | 現在のマーケットタブとタイムフレームでの順位 |
| Trader | 名前またはアドレス。ホバーでクイックアクションが表示されます |
| Account Value | 現在の合計エクイティ |
| Net PNL | 選択したタイムフレームのネット実現PNL。\$ または % |
| Volume | 取引された出来高 |
| Win Rate | 勝ちトレードの割合 |
| Trades | トレード数 |
| Top Assets | 累計出来高で最も多く取引された資産 |

数値の列は並べ替えできます。

## フィルターと検索

口座価値レンジ、勝率レンジ、トレーディングスタイルタグ（アルゴ、スキャルプ、イントラデイ、スイング）で行を絞り込めます。検索は名前でトレーダーを見つけ、任意の0xアドレスを貼り付ければ、読み込まれたランキングの外にいるトレーダーも検索できます。

## ここからできること

<Steps>
  <Step title="トレーダープロフィールを開く">
    任意の行をクリックすると、トレーダーの完全なプロフィールをプレビューできます。パフォーマンス統計、PNLチャートとカレンダー、ポジション、取引履歴。[ポートフォリオとアナリティクス](/jp/hyperdash/portfolio-analytics)で説明しているのと同じビューです。
  </Step>
  <Step title="追跡、コピー、Snoop">
    トレーダーにホバーするとクイックアクションが表示されます。**追跡**はウォレットを追跡中ウォレットに追加、**コピー**はアドレスをコピー、**Snoop**はそのトレーダーのアクティビティをターミナル上でライブでフォローします。
  </Step>
  <Step title="コピートレードを始める">
    トレーダーのプロフィールにあるコピースコアセクションには、セットアップフローを直接開くコピートレードボタンがあります。[コピートレーディング](/jp/hyperdash/copy-trade)を参照してください。
  </Step>
</Steps>

<Note>
  順位はネットの実現パフォーマンスから算出されるため、オープンポジションの未実現PNLでトレーダーの順位が上下することはありません。
</Note>
