<Note>
  Perp RFQは現在**プライベートベータ**です。[アクセスをリクエスト](https://hyperdash.com/rfq)すると、当社チームが利用資格を確認します。
</Note>

Perp RFQ（見積依頼）は、機関投資家グレードの流動性をオンデマンドでHyperdashにもたらします。大口注文を見えている板で少しずつ執行する代わりに、ホワイトリスト登録されたマーケットメーカーに流動性をリクエストすると、彼らはオーダーブックに直接双方向の流動性を追加する形で応答します。より大きなサイズ、より良い執行、より良い価格です。

## RFQの仕組み

<Steps>
  <Step title="リクエストを送信する">
    トレードパネルの**RFQ**タブを開き、市場を選んで、サイズをUSDC建てまたは資産建てで指定します。買い/ロングまたは売り/ショートを選択します。**売買方向を公開する**にチェックを入れない限り、方向はマーケットメーカーに開示されません。
  </Step>
  <Step title="マーケットメーカーが応答する">
    ホワイトリスト登録されたマーケットメーカーはリクエストの市場とサイズを受け取り、**5秒**以内に応答するか見送ります。応答したマーケットメーカーは、公開のオーダーブックに実際の双方向の流動性を直接追加します。
  </Step>
  <Step title="板の改善を確認する">
    RFQチケットは、流動性が追加されるにつれてオーダーブックを追跡し、更新された推定スリッページ、平均執行価格、RFQ前の板と比較した改善幅を表示します。
  </Step>
  <Step title="取引するか、見送るか">
    執行の猶予は**30秒**です。確定するまで何も取引されず、リクエストのキャンセルも、そのまま失効させることもいつでも可能です。
  </Step>
</Steps>

## 主要パラメータ

| パラメータ | 値 |
| --- | --- |
| 最大注文サイズ | リクエストあたり想定元本 \$500,000 |
| 実行ウィンドウ | 30秒、経過するとリクエストは失効 |
| マーケットメーカーの応答時間 | 流動性の追加または見送りまで5秒 |
| サイズ入力 | USDC想定元本または原資産数量 |
| 方向 | デフォルトでマーケットメーカーに非公開、任意で公開可能 |
| アクセス | プライベートベータ、招待制 |

## FAQ

<AccordionGroup>
  <Accordion title="アクセスを取得するには？">
    Perp RFQは現在プライベートベータで、招待制です。[アクセスをリクエスト](https://hyperdash.com/rfq)すると、当社チームが利用資格を確認します。
  </Accordion>

  <Accordion title="マーケットメーカーには何が見えますか？">
    リクエストの市場とサイズです。**売買方向を公開する**を有効にしない限り、取引の方向は非公開のままです。
  </Accordion>

  <Accordion title="方向を公開する意味はありますか？">
    公開すると、マーケットメーカーは両サイドではなく片側だけに流動性を追加すればよくなるため、提示価格がタイトになる可能性があります。非公開にすれば意図を悟られずに済みます。リクエストごとに選択できます。
  </Accordion>

  <Accordion title="リクエストしたら必ず取引しなければなりませんか？">
    いいえ。追加された流動性は公開のオーダーブックに残ります。執行するかどうかはあなたが選び、何もしなければリクエストは30秒後にそのまま失効します。
  </Accordion>

  <Accordion title="RFQに追加費用はかかりますか？">
    かかりません。RFQの利用に追加手数料はありません。執行された注文には通常のHyperdash取引手数料が適用されます。
  </Accordion>

  <Accordion title="どのマーケットメーカーも応答しなかったらどうなりますか？">
    リクエストは30秒後に失効し、何も執行されません。新しいリクエストはいつでも送信できます。
  </Accordion>
</AccordionGroup>
