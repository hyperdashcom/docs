您的个人主页汇集了与您自己账户有关的一切：总权益、持仓、进行中的订单、完整交易历史，以及基于您的交易计算的绩效分析。Hyperdash 上每个交易者主页都使用同一套布局，因此您在别人身上研究的统计指标，正是您在自己身上看到的指标。

## 账户总览

| 板块 | 显示内容 |
| --- | --- |
| 账户价值 | 总权益，按永续、现货、已质押和跟单余额细分 |
| 概览 | 未实现盈亏、账户杠杆、保证金使用率、历史盈亏和成交量 |
| 绩效 | 回撤、胜率和夏普比率，可在 7D、30D 和全部时间之间切换 |
| 分析 | 最长连胜、交易风格、平均和中位持仓时长，以及您所属的盈亏和规模群组 |

交易风格按平均持仓时长分类：剥头皮（15 分钟以内）、日内（15 分钟到 6 小时）、波段（6 小时到 2 周）、持仓（超过 2 周）或算法。旁边的小组件一目了然地展示您的多空方向偏好、杠杆和保证金使用率。

## 盈亏视图

- **图表**：在账户**价值**和**盈亏**之间切换，范围可选**永续**或**合并**，周期为 24H、7D、30D 或全部时间。
- **日历**：每日盈亏热力图。每一天按当日结果的大小标为绿色或红色，悬浮提示显示盈亏和收益率（ROE）。
- **盈亏日历**：按月翻阅的历史视图，包括您以天数计的最长连续盈利纪录。

## 持仓、订单与历史

| 标签页 | 内容 |
| --- | --- |
| 持仓 | 持仓及其入场价、标记价、盈亏和收益率（ROE） |
| 余额 | 现货代币余额 |
| 订单 | 挂单 |
| 成交 | 最近的订单成交记录 |
| 交易 | 已完成的交易，可按结果、方向、资产、名义价值和数量筛选 |
| TWAP | 进行中和已成交的 [TWAP](/cn/hyperdash/orders/twap) 订单 |
| 转账 | 充值和提现历史 |
| 绩效 | 最佳交易和按资产细分的资产绩效 |
| 跟单 | 您的跟单钱包，可按运行中、已停止或已归档筛选 |

您可以直接从表格中将任意仓位或您的盈亏分享为图片卡片。

## 资金分配

当一个跟单钱包跟随多位交易者时，分配编辑器负责在他们之间分配其资金：**平均**分配，或按交易者设置**自定义**权重滑块。分配总和必须为 100%，且每位被跟随的交易者的份额都必须大于 0%。完整设置流程参见[跟单交易](/cn/hyperdash/copy-trade)。

<Note>
  您的个人主页还会显示费用等级进度、邀请链接和返现统计。参见[费用、邀请与奖励](/cn/hyperdash/fees-referrals-rewards)。
</Note>
