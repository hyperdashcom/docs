---
title: "Layouts"
description: "Bauen Sie Ihr eigenes Trading-Terminal aus Widgets, speichern Sie es in Ihrem Konto und teilen Sie es mit anderen."
---

Das Hyperdash-Terminal ist ein Raster, das Sie selbst anordnen. Ihr **Workspace** ist alles, was Sie eingerichtet haben, und **Layouts** sind die Tabs darin. So halten Sie ein chartlastiges Layout fürs Scalping bereit, ein Flow-Layout zum Beobachten von Kohorten und ein Portfolio-Layout zum Durchsehen von Positionen, und wechseln mit einem Klick.

Alles wird automatisch in Ihrem Konto gespeichert. Melden Sie sich auf einem anderen Rechner an, kommt Ihr Workspace mit.

## Layout-Tabs

Jedes Layout ist ein Tab oben im Terminal. Über **Layout-Optionen** an einem Tab können Sie:

- **Umbenennen**
- **Duplizieren**, um eine Variante abzuzweigen, ohne das Original zu verlieren
- **Zurücksetzen** auf die ursprüngliche Anordnung
- **Teilen**, siehe unten
- **Schließen**

**Neues Layout** fügt einen weiteren Tab hinzu. Sie können mit einem leeren Raster beginnen oder ein bestehendes Layout als Ausgangspunkt wählen.

## Ein Layout aufbauen

Öffnen Sie die Schublade **Widget hinzufügen**, um alles Verfügbare zu sehen, gruppiert in Charts, Feed, Portfolio, Alpha und Tools, mit Suchfeld und einer Vorschlagsliste. Ziehen Sie ein Widget auf das Raster, um es zu platzieren.

Sobald Widgets im Raster liegen:

- Ziehen Sie ein Widget an seiner Kopfleiste, um es zu verschieben, und lassen Sie es auf einem anderen Widget los, um beide als Tabs in einem Panel zu stapeln
- Ziehen Sie eine Panel-Kante, um die Größe zu ändern
- **Maximieren** füllt den Bildschirm mit einem Widget, **Wiederherstellen** setzt es zurück
- **Lösen** hebt ein Widget aus dem Raster heraus
- Ziehen Sie ein Widget heraus und lassen Sie los, um es zu entfernen
- **Snapshot** kopiert oder lädt ein Bild eines einzelnen Widgets oder des gesamten Layouts

Die meisten Widgets lassen sich mehrfach hinzufügen, und genau darum geht es bei Link-Gruppen: zwei Preischarts auf unterschiedlichen Assets nebeneinander. Einige sind Einzelinstanzen, darunter Positionen, Guthaben, Offene Orders, Ausführungen, Transfers, Verlauf, Watchlist und Copytrade, da eine zweite Kopie dieselben Daten zeigen würde.

## Speichern

Gespeichert wird automatisch. Es gibt keinen Speichern-Button, und die Schublade sagt es selbst: Änderungen werden gespeichert, während Sie sie vornehmen.

<Note>
  Ihr Workspace ist ein einziger Datensatz pro Konto. Wenn das Terminal in zwei Tabs oder auf zwei Rechnern offen ist und beide gleichzeitig speichern, kann der spätere Speichervorgang abgelehnt werden, um den anderen nicht zu überschreiben. Laden Sie den Tab neu, in dem Sie weiterarbeiten möchten, und machen Sie dort weiter.
</Note>

## Ein Layout teilen

**Teilen** veröffentlicht ein Layout und vergibt einen Link unter `hyperdash.com/layout/<name>`. Wer ihn öffnet, sieht Ihre Anordnung und kann sie dem eigenen Workspace hinzufügen. Geteilt wird die Struktur des Layouts, also welche Widgets Sie verwendet haben und wie sie angeordnet sind, nicht Ihre Positionen, Guthaben oder Kontodaten.

Sie können jederzeit die Veröffentlichung zurücknehmen; danach lässt sich der Link von allen, die ihn noch nicht importiert haben, nicht mehr öffnen.

## Das Layout einer anderen Person nutzen

Öffnen Sie einen geteilten Layout-Link, bietet Hyperdash an, ihn als neuen Tab in Ihren Workspace zu importieren. Importierte Layouts gehören Ihnen: Änderungen wirken sich nicht auf das Original aus, und wer es geteilt hat, kann Ihres nachträglich nicht ändern.

Die Layout-Schublade trennt **Meine Layouts**, **Importiert** und **Empfohlen**, damit ein zugeschicktes Layout nie mit einem selbst gebauten verwechselt wird.
