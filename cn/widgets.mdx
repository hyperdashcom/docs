组件是构成[布局](/cn/layouts)的面板。打开**添加组件**抽屉，搜索或按类别浏览，然后拖到网格上。

## 图表

| 组件 | 说明 |
| --- | --- |
| 价格图表 | 某个市场的完整交易图表，配有绘图工具和指标。 |
| 爆仓图表 | 清算热力图，显示杠杆持仓在何处被强制平仓。参见[交易指标](/cn/trading-indicators)。 |
| 止损图表 | 止损热力图，显示止损单密集分布的位置。 |
| 历史资金费率 | 永续市场资金费率的历史走势，用于识别持续的多头或空头压力。 |
| 群组热力图 | 在单一网格中呈现各市场的群组持仓分布，一眼看清哪些群体在哪里做多或做空。 |
| Price heatmap | 一组标的的价格表现，按涨跌幅确定大小与颜色。 |

## 信息流

| 组件 | 说明 |
| --- | --- |
| 订单簿 | 所链接市场的实时买卖挂单与深度。 |
| 订单簿 (Node) | 直接来自 Hyperliquid 节点的订单簿。 |
| 交易 | 所链接市场的实时成交记录。 |
| 新闻 | 实时头条。点击头条上的代币标签即可用[快捷交易](/cn/quicktrade)就地下单。 |

## 投资组合

| 组件 | 说明 |
| --- | --- |
| 持仓 | 您的持仓，包含开仓价、强平价、数量和未实现盈亏。 |
| 余额 | 您在永续和现货账户中的余额。 |
| 挂单 | 您挂在盘口的委托，可直接在表格中撤单。 |
| TWAP | 您自己正在执行的 TWAP 订单及其进度。 |
| 当前TWAP | 其他交易者在您当前查看市场上的活跃 TWAP。 |
| 成交 | 您的逐笔成交。 |
| 历史 | 您已完成的交易历史。 |
| 转账 | 账户的充值、提现与转账记录。 |
| 跟单 | 您正在进行的跟单关系及其表现。参见[跟单交易](/cn/copy-trade)。 |
| 关注列表 | 您加星标的标的。同时可作为其他组件跟随的来源，详见下文。 |

## 组件链接

默认情况下，每个组件显示各自指定的标的。链接把组件绑在一起，在其中一个里切换标的时，其余组件也会一同切换。正是这一点，让一堆组件变成一个真正好用的终端。

### 链接组

共有六个链接组，各有一种颜色。打开组件标题栏中的链接菜单并选择颜色，即可将该组件加入对应的组。

| 组 | 颜色 |
| --- | --- |
| 1 | 蓝色 |
| 2 | 黄色 |
| 3 | 紫色 |
| 4 | 红色 |
| 5 | 橙色 |
| 6 | 青色 |

同一组内的所有组件跟随同一标的。把价格图表、订单簿和成交信息流放进蓝色组，它们就会一起联动。再把另一组放进黄色组，您就能同时盯两个市场，而彼此互不干扰。

不需要联动的组件可以设为**无**，这样无论布局其余部分如何变化，它都会停留在您指定的标的上。

### 目标

**目标**是一个独立的、不带编号的角色。设为目标的组件跟随您当前正在交易的标的，而不是某个颜色组。只有价格图表和快捷交易可以担任目标角色。

### 跟随关注列表

链接并不限于单个标的。**关注列表**和 **Price heatmap** 组件可以作为一个组的来源，此时它们传递给跟随组件的是一整份标的清单，而不是单个交易对。

这就是用清单驱动布局的方式：给关心的标的加星标，把布局的其余部分指向关注列表，支持接收清单的组件便会遍历您的整个关注列表，而不是只看一个市场。

<Note>
  并非所有组件都能链接。持仓、余额、成交等展示您自身账户数据的组件，反映的是您本人而非某个市场，因此没有可跟随的对象。
</Note>
