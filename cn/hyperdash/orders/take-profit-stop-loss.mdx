title: "止盈和止损"

止盈和止损（TP/SL）预先定义您的离场：止盈在盈利价位平掉部分或全部仓位，止损限制您的下行风险。您可以在下单时附加 TP/SL，也可以将其添加到任何持仓上，并分别选择每条离场的执行方式。

## 下单机制

- 每一条都是触发单。价格到达触发价前，订单簿上不会新增任何挂单；到达后，离场订单自动挂出。
- 每条可按价格设置，也可按 % 或 \$ 计的收益/亏损设置。另一个字段会根据您的入场价和仓位大小自动换算。
- 每条离场的执行方式可选：**市价**立即平仓，滑点上限 5%；**限价**在触发价挂单；**追价**跟随最优买价或卖价；**TWAP** 在设定窗口内分批离场。
- 先触发的一条先启动离场，策略会持续跟踪，直到设定数量平仓完毕。
- **设置数量**可以只平掉仓位的一部分而非全部，按仓位百分比或固定资产数量设置。

## 适用场景

- 一步为仓位同时设好盈利目标和风险下限。
- 不盯盘也能执行风险纪律。
- 分批离场：在目标位部分止盈，同时止损覆盖全部仓位。

## 参数

| 参数 | 说明与选项 | 默认值 |
| --- | --- | --- |
| 止盈价 / 收益 | 止盈触发。输入价格，或以 % 或 \$ 计的收益。多头必须高于标记价，空头必须低于标记价。 | 无 |
| 止损价 / 亏损 | 止损触发。输入价格，或以 % 或 \$ 计的亏损。多头必须低于标记价，空头必须高于标记价。 | 无 |
| 订单类型（每条独立） | 触发后以市价、限价、追价或 TWAP 执行。 | 市价 |
| 时长（仅 TWAP） | TWAP 离场分批执行的窗口，30 秒到 1 小时。 | 5m |
| 设置数量（可选） | 部分离场的数量，按仓位百分比或资产数量。 | 仓位的 100% |

止盈和止损至少需要设置一个，也可以在同一仓位上同时设置。

## 示例

您以 \$65,000 的入场价持有 0.2 BTC 多仓。您在 \$71,500（收益 10%）设置止盈，离场方式为限价；在 \$61,750（亏损 5%）设置止损，离场方式为市价，均为全部数量。如果 BTC 涨到 \$71,500，一笔限价卖单会挂在该价位。如果 BTC 反而跌到 \$61,750，仓位立即以市价平掉，滑点上限 5%。

<Note>
  非市价离场存在成交风险：限价、追价或 TWAP 离场在快速行情中可能无法完全平掉仓位。如果市场跳空越过您的价位，市价止损的成交价也可能比触发价更差。
</Note>
