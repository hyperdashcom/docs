---
title: "阶梯订单"
description: "在一张订单中于价格区间内挂出一组阶梯限价单。"
---

阶梯订单将一笔订单拆分为您定义的价格区间内的一组阶梯限价单，目标是获得比单笔成交更优的平均价格。在交易面板的**高级**选择器下可以找到阶梯订单。

## 下单机制

- 一次性将您设定的订单数量挂为一笔笔独立的限价单，全部为直到取消前有效（GTC）。
- 价格从起始价到结束价均匀分布。
- 各笔订单的数量按规模倾斜在阶梯上线性变化，且总和始终等于您的总数量。当订单数量为 1 时，全部数量挂在起始价。
- 每笔订单独立成交，因此较浅的行情波动只会成交阶梯的一部分。

## 适用场景

- 在一个区间内逢弱吸筹或逢强派发，而不是只押一个价格。
- 预期区间内震荡时，分批建仓摊平入场成本。
- 通过规模倾斜将更多数量分配到区间远端。

## 参数

| 参数 | 说明与选项 | 默认值 |
| --- | --- | --- |
| 数量 | 所有订单的总量，以资产或 USD 计。 | 无 |
| 起始价 | 第一笔订单的价格。点击**中间价**可预填当前中间价。 | 无 |
| 结束价 | 最后一笔订单的价格。 | 无 |
| 订单数量 | 阶梯中限价单的数量，1 到 100。 | 无 |
| 规模倾斜 | 最后一笔订单与第一笔订单的数量之比。1.0 为等量分配；2.0 表示结束端订单是起始端的两倍。 | 1.00 |
| 只减仓（可选） | 持有仓位时显示。订单只能减少仓位。 | 关 |

挂出阶梯前，面板会预览第一笔和最后一笔订单、平均价格、订单价值和所需保证金。

## 示例

HYPE 价格为 \$40，您想在下跌中建立 100 HYPE 的多仓：起始价 \$40，结束价 \$36，订单数量 5，规模倾斜 2.0。Hyperdash 会在 \$40、\$39、\$38、\$37 和 \$36 挂出限价买单，数量分别为 13.3、16.7、20、23.3 和 26.7 HYPE。如果整个阶梯全部成交，您的平均入场价约为 \$37.67，而等量分配时为 \$38.00。

<Note>
  阶梯中每笔订单的价值必须至少为 \$10。如果最小的一笔订单低于该值，面板会发出提醒：请降低订单数量或增加总数量。
</Note>
