프로필은 내 계정에 관한 모든 것의 홈입니다. 총 자산 가치, 오픈 포지션, 진행 중인 주문, 전체 트레이딩 기록, 그리고 거래로부터 계산된 성과 분석이 모여 있습니다. Hyperdash의 모든 트레이더 프로필이 같은 레이아웃을 사용하므로, 다른 트레이더를 분석할 때 보는 지표를 내 계정에서도 그대로 보게 됩니다.

## 계정 개요

| 섹션 | 표시 내용 |
| --- | --- |
| 계정 가치 | 퍼프스, 스팟, 스테이킹, 카피트레이드 잔고로 나뉜 총 자산 가치 |
| 개요 | 미실현 PNL, 계정 레버리지, 마진 사용률, 누적 PNL, 거래량 |
| 성과 | 낙폭, 승률, 샤프 비율, 7D / 30D / 전체 기간 전환 가능 |
| 분석 | 최장 연승, 트레이딩 스타일, 평균 및 중앙값 거래 기간, 나의 PNL 및 규모 코호트 |

트레이딩 스타일은 평균 거래 기간으로 분류됩니다. 스캘핑(15분 미만), 데이 트레이딩(15분에서 6시간), 스윙(6시간에서 2주), 포지션(2주 초과), 또는 알고리즘입니다. 옆의 위젯들은 롱/숏 방향 편향, 레버리지, 마진 사용률을 한눈에 보여줍니다.

## PNL 보기

- **차트**: 계정 **가치**와 **PNL** 사이를 전환하며, **퍼프스** 또는 **합산** 범위로 24H, 7D, 30D, 전체 기간을 볼 수 있습니다.
- **캘린더**: 일별 손익 히트맵입니다. 하루하루가 결과의 크기에 따라 초록 또는 빨강으로 칠해지고, 툴팁에 PNL과 ROE가 표시됩니다.
- **PNL 캘린더**: 월 단위 보기로 과거 기록을 넘겨볼 수 있으며, 일 수 기준 최장 플러스 연속 기록도 포함합니다.

## 포지션, 주문, 기록

| 탭 | 내용 |
| --- | --- |
| 포지션 | 진입가, 마크 가격, PNL, ROE와 함께 표시되는 오픈 포지션 |
| 잔고 | 현물 토큰 잔고 |
| 주문 | 미체결 주문 |
| 체결 | 최근 주문 체결 내역 |
| 거래 | 완료된 거래, 결과, 방향, 자산, 명목 가치, 수량으로 필터링 가능 |
| TWAP | 진행 중이거나 체결된 [TWAP](/ko/orders/twap) 주문 |
| 이체 | 입출금 기록 |
| 성과 | 베스트 거래와 자산별 성과 분석 |
| 카피트레이드 | 실행 중, 중지됨, 보관됨으로 필터링되는 내 카피트레이드 지갑 |

테이블에서 바로 포지션이나 PNL을 이미지 카드로 공유할 수 있습니다.

## 자본 배분

카피트레이드 지갑이 두 명 이상의 트레이더를 팔로우하면 배분 편집기가 자본을 그들에게 나눕니다. **균등** 분할 또는 트레이더별 **커스텀** 가중치 슬라이더입니다. 배분 합계는 100%여야 하고, 추적하는 모든 트레이더의 몫은 0%보다 커야 합니다. 전체 설정 과정은 [카피 트레이딩](/ko/copy-trade)을 참고하세요.
